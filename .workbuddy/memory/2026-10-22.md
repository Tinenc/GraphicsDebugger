## 03:30 直启失败根因

```
[SDK] PC launch auth extraInfo failed, code: 1, errorCode: 10100,
      filePath: c:\program files\graphicsdebugger-wuthering-waves\x64\development\qtinecmatool.exe
[Critical] NullReferenceException: ... at Beyond.GameApp._UnInitGameStateMachine
```

- `filePath` = **当前进程 exe 路径** → SDK 校验的是"谁启动了我"，不是命令行参数
- 调用栈：`SendMessage("OnExtraInfo")` → `U8.SDK.SDKInterfaceWIN:HGU8SDKSetData`
  → launcher 经 U8SDK 私有通道传 token，不走命令行
- 失败后 NRE 自杀（`OnDestroy`），exit 正常

⇒ 与鸣潮的 `-krqlv` **完全不同性质**，补命令行参数无效；必须让 `Games.exe` 拉起来

## 03:40 落地两个工具

### `tools/layer_ctl.ps1`
- `-Status`（默认也打印，只读）：列 TinecmaTool/renderdoc 相关条目，逐个标 json/dll 的 OK/MISS，
  多条同名时告警；顺带打印 `ENABLE_...` 的 User/Process 值
- `-Clean`（需管理员）：删 MISS 条目 + 同名重复，只保留 `-LayerJson` 指定那条
  （默认指向 Wuthering-Waves 的 10-22 构建）
- `-Register`（需管理员）：把 json 写进 HKLM
- `-On` / `-Off`：写/清 User 环境变量，`-Off` 同时置 `DISABLE_..._1_44=1`
- 实测 `-Status` 输出正确，5 条全部识别

### `tools/endfield_probe.ps1`
- 只读。每 250ms 扫 `Win32_Process`，进程名正则
  `^(Launcher|Games|Uninstall|Updater|Patch|Endfield|UnityCrashHandler64)$|^ACE|AntiCheat|CrashSight|^SGuard|PlatformProcess|^QtWebEngineProcess$`
- 新进程记 PID/PPID/完整命令行；`Endfield.exe` 出现后单独跟踪模块，
  正则 `vulkan-1|nvoglv|TinecmaTool|GameAssembly|UnityPlayer|ACE-|ACE_|anticheat|...`
- 跑完输出：存活时长、exit code（十六进制）、模块时间线、进程树、判读指南
- 前置段落打印 ImplicitLayers 各条目的 json/dll 存在性，日志自带"当时武装了哪个 layer"的证据
- 日志 `%TEMP%\TinecmaTool\endfield_probe_<stamp>.log`
