TinecmaTools 使用说明
========================

编码问题解决方案
================

如果您遇到中文乱码问题，请使用以下方法之一：

方法 1: 使用 PowerShell 脚本（推荐）
------------------------------------
直接运行 PowerShell 版本，完美支持中文：

    右键点击 example_usage.ps1 -> 使用 PowerShell 运行

或在 PowerShell 中执行：
    .\example_usage.ps1


方法 2: 使用英文版批处理
-----------------------
已创建英文版批处理文件，避免编码问题：

    双击运行 example_usage.bat

所有提示信息均为英文，功能完全相同。


方法 3: 使用快速启动脚本
-----------------------
双击运行：

    run_example.bat

此脚本会自动调用 PowerShell 版本。


方法 4: 直接使用 Python 工具
----------------------------
在 PowerShell 或 CMD 中运行：

    python tools\auto_bypass.py --renderdoc "C:\Program Files\RenderDoc" --game "游戏路径"


常用命令快速参考
===============

1. 自动化模式（一键完成）:
   python tools\auto_bypass.py --renderdoc "RenderDoc路径" --game "游戏路径"

2. 重命名文件:
   powershell -ExecutionPolicy Bypass -File tools\rename_tool.ps1

3. 修改字符串:
   python tools\string_replacer.py "文件路径"

4. 注入 DLL:
   powershell -ExecutionPolicy Bypass -File tools\inject_dll.ps1 -ProcessName "进程名" -DllPath "DLL路径"


故障排除
========

问题：批处理文件显示乱码
解决：使用 PowerShell 版本（example_usage.ps1）或英文批处理版本

问题：PowerShell 脚本无法运行
解决：以管理员身份运行 PowerShell，执行：
      Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

问题：Python 命令无法识别
解决：确保已安装 Python 3.7+，并添加到系统 PATH
